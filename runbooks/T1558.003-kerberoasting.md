# Runbook: T1558.003 Kerberoasting

**Plan:** A · **Tactic:** Credential Access · **Target:** DC01 from WS01
**Detection expected:** Wazuh rule **100010** (Event 4769, RC4/0x17 TGS for an SPN)

## What the technique does
Requests a Kerberos service ticket (TGS) for an account that has a Service Principal
Name (here `svc_sql` / `MSSQLSvc/dc01.lab.local`). The DC returns a ticket encrypted with
the service account's password hash; if RC4 is allowed the ticket can be cracked offline.

## Atomic test
Atomic Red Team **T1558.003**. The portable atomic uses PowerView/Rubeus:

```powershell
# from an elevated PowerShell on WS01, as a domain user
Invoke-AtomicTest T1558.003 -TestNumbers 1 -GetPrereqs
Invoke-AtomicTest T1558.003 -TestNumbers 1
```

Manual equivalent (what I actually verified in ad-attack-chain, from Kali):
`impacket-GetUserSPNs lab.local/a.mokaya -request` → RC4 hash → John.

## Expected telemetry
- **DC01 Security 4769**: "A Kerberos service ticket was requested",

- Shipped to Wazuh by the DC01 agent.
