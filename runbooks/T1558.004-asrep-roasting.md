# Runbook: T1558.004 AS-REP Roasting

**Plan:** A · **Tactic:** Credential Access · **Target:** DC01 from WS01
**Detection expected:** Wazuh rule **100011** (Event 4768, PreAuthType 0)

## What the technique does
Requests a Kerberos AS-REP for an account with "Do not require Kerberos
preauthentication" set (`b.otieno` in the lab). The DC returns an AS-REP whose encrypted
portion can be cracked offline: no valid credentials needed, just the username.
